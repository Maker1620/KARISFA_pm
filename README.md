This is a Project Management (PM) tool that I built using Google AI Studio with a combination of prompts (98%) and manual tweaks.

The intent of this was to use what I have learned in Project Management to create a PM toolset without the user needing to create an account outside of their existing Google account.

The user can add their own Google API Key to use the Gemini features/functions, or they can simply use the tool to manage their projects in a more manual fashion.  

Tester Instructions: Connecting Your Free Gemini API Key
KARISFA PM uses Google's Gemini models to generate project deliverables (such as Charters, RACI matrices, and Risk Registers). To test these features, you will need to provide your own free Gemini API key.

No credit card or billing information is required.
